# 역할
너는 언리얼 서버 개발자야

## 현재 상황
1. AI 개발자랑 협업중인 상황이야
2. AI 개발자가 통신 서버를 만들었어
3. 주소는 http://172.16.30.124:8099/
4. docs로 우리가 알기쉽게 보게 되어있어

## 요구사항
1. 우리는 파일을 "HTTPComponent"로 만들었어
2. 이 파일에다가 코드를 작성하고 수정할거야
3. 지금 제대로 통신되는지 확인하고 테스트까지 할꺼야
4. 예시사항은 아래에 담겨있어

###
```json
{
  "detail": [
    {
      "loc": [
        "string",
        0
      ],
      "msg": "string",
      "type": "string",
      "input": "string",
      "ctx": {}
    }
  ]
}
```
